Documentação da API NPS

API para gestão de pesquisas NPS, questionários, questões, respostas, alunos e cursos.

1. Questionário

GET /api/Questionario
Lista todos os questionários.
GET /api/Questionario/{id}
Busca um questionário pelo ID.
POST /api/Questionario
Cria um novo questionário. 
{
  "titulo": "Formulário Completo de Tipos de Questão",
  "dataCriacao": "2024-05-19T00:00:00Z",
  "dataExpiracao": "2024-05-26T00:00:00Z"
}
PUT /api/Questionario/{id}
Atualiza um questionário existente.
DELETE /api/Questionario/{id}
Remove um questionário.

2. Questão

GET /api/Questao
Lista todas as questões.
GET /api/Questao/{id}
Busca uma questão pelo ID.
POST /api/Questao
Cria uma nova questão. 
{
  "texto": "Qual seu turno de estudo?",
  "tipo": "RespostaUnica",
  "ordem": 3,
  "questionarioId": 1
}
PUT /api/Questao/{id}
Atualiza uma questão.
DELETE /api/Questao/{id}
Remove uma questão.
GET /api/Questao/tipos
Lista todos os tipos de questão disponíveis (enum).
GET /api/Questao/{questaoId}/opcoes
Lista as opções de uma questão fechada.
POST /api/Questao/{questaoId}/opcoes
Adiciona uma opção a uma questão fechada. 
{ "texto": "Matutino", "ordem": 1 }
DELETE /api/Questao/opcoes/{opcaoId}
Remove uma opção de questão.

3. Resposta

GET /api/Resposta
Lista todas as respostas.
GET /api/Resposta/{id}
Busca uma resposta pelo ID.
POST /api/Resposta
Envia as respostas de um aluno para um questionário. 
{
  "questionarioId": 1,
  "alunoId": 123,
  "respostasQuestoes": [
    { "questaoId": 1, "valor": "E-mail" },
    { "questaoId": 2, "valor": "Sim" },
    { "questaoId": 3, "valor": "Matutino" }
  ]
}
PUT /api/Resposta/{id}
Atualiza uma resposta.
DELETE /api/Resposta/{id}
Remove uma resposta.
